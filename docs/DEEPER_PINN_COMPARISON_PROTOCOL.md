# Deeper single-network Double Heston comparison

Requested source: `Double/Single-heston` from
`https://github.com/virajchoudhary/double-heston-inverse-calibration.git`, fetched
at `b0b461ac012a16894078f7906cd9efb50e204a9c`. Work is isolated on
`codex/deeper-double-pinn-comparison`. The user requested one deeper, more layered
Double Heston PINN and comparison against Single Heston, with price accuracy and
parameter recovery reported separately.

## Interpretation and fixed comparison

Each candidate is one conditional forward pricing network. Calibration optimizes
its frozen neural IV output only. There is no exact-price refinement, ensemble,
or generating truth passed to calibration. Fourier prices and sensitivities are
allowed as synthetic training references and for post-fit diagnostics.

Price comparison uses the **same observed surfaces, calibration strikes, heldout
strikes and optimizer budgets** for every model. Evaluate surfaces generated by
both Single and Double Heston; disclose which generator a result concerns.
Primary price metric: pooled normalized heldout-price RMSE from neural predictions.
Exact repricing of the fitted physical parameters is a separate diagnostic.

Own-model recovery is evaluated separately: five true Single Heston parameters
for Single Heston-generated data, and ten true Double Heston parameters for Double
Heston-generated data. Single Heston estimates on Double Heston data do not have
five generating Single Heston labels. Preserve the previous gates: every positive
parameter within 5%, each rho within .05. Report both the original scaled RMSE
(rho scaled by .5) and tolerance-scaled RMSE. A win on price does not imply a win
on parameter recovery, and recovering ten parameters is a different challenge
from recovering five.

The grid is 21 strikes from .8 to 1.2 of spot, six maturities
30/60/90/180/365/730 days, spot/forward 1 and zero carry. Every third strike is
held out. Geometry is synthetic, not a statement of NSE quote availability.
Truth units are sampled independently in [.1,.9]. Retain failures in counts.
Five starts and at most 400 evaluations per start for final comparison. No
model is selected by final test labels or prices.

## Sequential development

Original baselines: `single_sobolev_s17` and `double_sobolev_s17`, each five hidden
layers of width 160. Candidate networks add two-layer residual blocks initialized
to the identity, preserving the pretrained function before training. All blocks
belong to the same model and receive trainable gradients.

1. `deep11_s17`: 11 hidden dense layers, 477,473 parameters; 6,000 AdamW updates,
   seed 17, original parameter-sensitivity/PDE weights .2/.2, LR 5e-5. Selected
   step 4,000 by original four-case development parameter RMSE. It improved the
   shared DH-surface price benchmark but not own-model recovery.
2. `deep17_full_s29`: 17 hidden dense layers, six 384-wide residual blocks;
   16,000 updates, seed 29, full parameter and geometry derivative supervision
   .2/.2, PDE weight .0002, LR 2e-5. Lower PDE weighting is disclosed and requires
   independent PDE diagnostics; small forward errors are not proof of a solved PDE.
3. A final continuation from the selected 11-layer model uses LR 1e-5, PDE
   weight .02 and geometry-sensitivity weight .05, 8,000 updates, seed 43.

New synthetic reference data: seed 909210, 131,072 training and 16,384 validation
points (validation seed 909211), independently generated and checked at 128/96
quadrature nodes. The full derivative variant uses the same points and prices
and additionally supervises dg/dx and dg/dlog(tau), including the explicit Black
x derivative in implicit IV differentiation. Finite differences test these labels.

Training selection continues to use the original four recovery validation
surfaces (seed 906311). Additional exposed development comparison seed 909311
uses six truths per generator. Original Single Heston checkpoint is frozen.
Select the best trained deeper candidate by development parameter recovery,
then assess frozen models using fresh comparison seed 909831 with 24 truths per
generator. A paired 1% time-value-noise stress test uses the same truth seed.
No selection changes based on that final assessment may be called unseen.

The training-error-covariance diagnostic (seed 909451, 512 training surfaces) is
separate from the final neural-only comparison. Its four shrinkage choices were
examined on exposed development truths; it cannot establish unseen recovery and
does not replace ordinary fitting in the headline comparison.

All trials, source snapshots, scheduled checkpoints and unsuccessful results are
retained. These runs share a pretrained initialization; changing continuation
seeds does not make them independent from-scratch model initializations.
